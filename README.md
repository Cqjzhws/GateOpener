# GateOpener - 门禁一键开门插件

## 功能

- 在微信中显示浮动开门按钮
- 支持1单元1楼、负3楼两个门禁
- 自动从微信Cookie提取认证信息
- 自动计算签名并调用开门接口
- 按钮可拖动，自动吸附边缘

## 安装方法

### 前提条件
- iPhone已安装 **TrollStore**
- 微信版本 8.0.x（其他版本可能不兼容）

### 安装步骤

1. 下载 `GateOpener.deb` 文件到iPhone
2. 用 **Filza** 或 **Sileo** 打开deb文件
3. 点击安装
4. 打开微信，进入门禁小程序页面
5. 屏幕右侧会出现蓝色🚪浮动按钮
6. 点击按钮，选择要开的门

## 使用说明

1. **首次使用**：确保已在微信中登录过门禁小程序
2. **开门**：点击浮动按钮 → 选择楼层 → 等待结果提示
3. **移动按钮**：按住按钮拖动到任意位置，松手后自动吸附边缘
4. **Token过期**：如果提示"Cookie信息不完整"，请重新打开一次门禁小程序

## 技术原理

- 注入微信进程，在WKWebView上叠加浮动按钮
- 通过JavaScript读取页面Cookie获取accessToken/appKey
- 调用`getCookie`接口获取hashKey和服务器时间
- 使用SHA256算法计算签名
- 调用`open/v1`接口执行开门

## 文件结构

```
gateopener/
├── Makefile          # Theos编译配置
├── Tweak.xm          # 插件核心代码
├── GateOpener.plist  # 注入目标配置（微信）
└── control           # 包信息
```

## 构建

通过GitHub Actions自动构建：
1. 将代码推送到GitHub仓库
2. Actions自动运行，在macOS上编译
3. 构建产物为`.deb`文件，可直接安装
